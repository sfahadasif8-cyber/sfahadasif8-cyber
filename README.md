## ⭐ Featured Project

### [URL Shortener](https://github.com/sfahadasif8-cyber/url-shortener)

A production-style URL shortening service built with **FastAPI, PostgreSQL, Redis, Docker, Nginx, Alembic, and GitHub Actions**.

Includes:

- Custom and generated short URLs
- Redis caching and rate limiting
- Click analytics
- SHA-256 IP hashing
- PostgreSQL persistence
- Database migrations with Alembic
- Dockerized production setup
- Automated CI with GitHub Actions
- Free-tier cloud deployment

**Live:** https://url-shortener-ewec.onrender.com
